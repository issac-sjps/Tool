上傳 JSON 檔案 → 編輯 → 下載（保留原檔名），或將 XML 轉換為 JSON
尚未載入檔案
請點選「開啟 JSON 檔案」，或直接把 .json 檔案拖曳到這裡
提示：儲存下載時會直接用原檔名（例如 data.json → 下載後仍叫 data.json），瀏覽器可能會依你的下載設定詢問存檔位置或直接放進「下載」資料夾。若要覆蓋原檔案，下載後請自行搬移取代。
這個分頁只處理「基本資料」欄位對照。沒有來源資料的欄位會自動填 null，轉換後請務必在下方檢查並手動補齊標示 ⚠️ 的欄位（可切換到 JSON 編輯器分頁繼續編輯）。
